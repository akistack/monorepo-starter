# NestJS Fastify application

This template creates a NestJS 12 ESM application using Fastify, the Nest CLI's official Rspack builder, and Rstest.

## Get started

Start the development server:

```bash
pnpm run dev
```

Build and run the production bundle:

```bash
pnpm run build
pnpm run start:prod
```

Run tests:

```bash
pnpm run test
pnpm run test:coverage
```
