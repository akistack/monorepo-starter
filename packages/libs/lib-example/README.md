# Rslib project

This example targets Node.js 22 and produces bundled ESM, bundled CommonJS, and bundleless ESM outputs.

## Setup

Install the dependencies:

```bash
pnpm install
```

## Get started

Build the library:

```bash
pnpm run build
```

Build the library in watch mode:

```bash
pnpm run dev
```
